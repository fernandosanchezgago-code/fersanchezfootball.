# FerFootBall

Primera versión de una web de fútbol español, adaptable a móviles y ordenadores.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño oscuro y moderno.
- `script.js`: menú móvil.

## Importante antes de publicar
Esta versión es una maqueta funcional de diseño. Los marcadores, la clasificación y las noticias son contenido de ejemplo, no datos en directo. Sustitúyelos por información verificada o conecta una API de fútbol con sus permisos y condiciones antes de anunciar resultados como actuales.

## Publicar gratis con GitHub Pages
1. Crea una cuenta en GitHub con ayuda de un adulto si hace falta.
2. Crea un repositorio público llamado `ferfootball`.
3. Sube los tres archivos (`index.html`, `styles.css`, `script.js`) a la raíz.
4. En el repositorio entra en **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
6. GitHub te dará una dirección pública similar a `https://TU-USUARIO.github.io/ferfootball/`.

Para usar un dominio propio (por ejemplo, ferfootball.es), hay que comprobar que esté libre y registrarlo por separado.
